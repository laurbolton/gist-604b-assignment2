GIST 604B Assignment 2: QGIS Desktop GIS Projects
Lauren Bolton

## Overview
This repository documents the completion of QGIS tutorials and demonstrates technical skills developed through hands-on exercises. These skills include querying data using expressions, performing table and spatial joins, working with delimited text, reprojecting layers, and symbolizing map features. The repository is organized into a "projects" folder containing the .qgz project files and an "outputs" folder with the results from each tutorial.

## Software Environment
**QGIS Version Used:** 4.0.0-Norrköping  
**Operating System:** Windows 11 Pro  
**Plugins Used:** not applicable

## Reflection
Completing the QGIS tutorials helped to highlight the similarity of the software's core functionality to ArcGIS Pro. The hands-on experience provided a refresher on concepts like working with delimited text and reprojecting layers. The tutorials were well-designed and easy to follow, which helped make the transition between platforms more intuitive than expected. However, troubleshooting was more difficult simply because I am unfamiliar with the interface. The most challenging aspect was styling; the process felt convoluted and I struggled to find a straightforward way to adjust symbology the way that I'm used to. Moving forward, I anticipate applying these QGIS skills in future spatial analyses. I think there is value in becoming proficient with the software given that it's free and open source, which makes it an accessible option for individuals and organizations that don't have the budget for Esri licenses.
