## Project Description
This project documents a series of QGIS-based workflows focused on desktop GIS analysis. It highlights technical skills in data management, spatial analysis, and cartographic design developed through hands-on tutorials using vector and raster data.

## Tools and Technologies
- QGIS (v4.0.0-Norrköping)
- [QGIS Tutorials and Tips](https://www.qgistutorials.com/en/index.html)

## What I Did
- Queried data using attribute expressions
- Performed table and spatial joins
- Imported delimited text files and created feature layers
- Visualized temporal change using raster data

## How to View/Run
- Open .qgz project files located in the **projects** folder using QGIS
- View exported maps and outputs in the **outputs** folder
